## Strings

A finite [[Sequence Definition#Sequence|sequence]] of [[Set Definitions#Element|elements]]. Given set $A$, we can construct the set $A^*$ (**string** over $A$), consisting of all *finite sequences of elements* of $A$.

> [!Example]
> $A = \{ x \mid x \text{ is a letter in the English alphabet } \}$
> 
> $A^*$ consists of all ordinary words, whether they have meaning or not.

## Order

Unlike sets, the order in which the [[Set Definitions#Element|elements]] in the **string** is written is *important*.

> [!Example]
> $\text{Let } X = \{ a, b, c \} \qquad baac \neq acab \qquad bbaaac = b^2 a^3 c$

## Length

The **length** of a string $\alpha$ is the number of [[Set Definitions#Element|elements]] in $\alpha$, denoted by $|\alpha|$.

> [!Example]
> $\alpha = aabab \qquad |\alpha| = 5$
> 
> $\beta = a^3 b^4 a^32 \quad\enspace |\beta| = 39$

## Null String

A **string** with no [[Set Definitions#Element|elements]], denoted by $\lambda$ (also called *empty string*).
