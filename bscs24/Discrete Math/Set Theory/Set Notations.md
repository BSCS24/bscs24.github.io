## Semantic Form

The simplest way to represent a [[Set Definitions#Set|set]] is a statement to describe the [[Set Definitions#Element|elements]] it is comprised of. These can be simple phrases.

> [!Example]
> - collection of all wooden chairs
> - collection of real numbers between 0 and 1

## Roster Form

One way of describing a [[Set Definitions#Set|set]] that has a [[Set Properties#Cardinality|finite number]] of [[Set Definitions#Element|elements]] is by listing them between braces $\{ \: \}$.

> [!Example]
> - set of all positive integers less than four
> 	- $A = \{ 1, 2, 3 \}$ 
> - set of all vowels in the English alphabet
> 	- $V = \{ a, e, i, o, u \}$

When the general pattern of the [[Set Definitions#Element|elements]] is obvious, all members of the [[Set Definitions#Set|set]] may need not be explicitly described; instead, ellipses ($…$) can be used.

> [!Example]
> - set of positive integers less than 100 
> 	- $P = \{ 1, 2, 3, \ldots, 99 \}$


## Set Builder Form

If a set is a large [[Set Properties#Cardinality|finite set or an infinite set]] , we describe it by specifying a property that the [[Set Definitions#Element|elements]] of the [[Set Definitions#Set|set]] have in common using the form $\{ x \:|\: P(x) \}$. The vertical bar `|` used in this notation stands for *"such that"*. Sometimes a colon `:` is used in the place of the `|`.

> [!Example]
> - $B = \{ x \mid x \text{ is a positive integer less than 4 } \}$
> - $C = \{ x \mid x \text{ is a Computer Science student } \}$
