## Set

A set is any well-defined, unordered collection of objects (also called [[Set Definitions#Element|elements]] or members). 

## Element

Elements are typically [mathematical objects](https://en.wikipedia.org/wiki/Mathematical_object "Mathematical object") of any kind: numbers, symbols, points in space, lines, other geometrical shapes, variables, or even other [[Set Definitions#Set|sets]].

## Tuple

A tuple is a finite [sequence](https://en.wikipedia.org/wiki/Sequence "Sequence") or _ordered list_ of [[#Element|elements]]. An **n-tuple** is a tuple of n elements, where n is a non-negative [integer](https://en.wikipedia.org/wiki/Integer "Integer"). There is only one 0-tuple, called the _empty tuple_. A 1-tuple and a 2-tuple are commonly called a [singleton](https://en.wikipedia.org/wiki/Singleton_\(mathematics\) "Singleton (mathematics)") and an [ordered pair](https://en.wikipedia.org/wiki/Ordered_pair "Ordered pair"), respectively.
